# pesttoclear.com

PestToClear: a pest-control matching service in Singapore, run by the OurKampung team and part of the
OurKampung family. Enquiries arrive through a FormSubmit form, and the team passes each one to a partner
pest-control firm. Built the way HomeToClean is (structure copied, not text). Brief:
`../jtc-family/briefs/pesttoclear.md`; independence: `../jtc-family/briefs/independence.md`.

## Stack

Astro 5 + Tailwind 4, static output, `trailingSlash: 'always'`. Deployed by `.github/workflows/deploy.yml`
(GitHub Actions to Pages). `public/CNAME` and `public/.nojekyll` must stay in the published output.
GA4 comes from the `PUBLIC_GA4_ID` build variable (a repo variable in CI); without it no analytics loads.
Illustrations in `public/illo/` are generated by `npm run illo` (`scripts/illustrations.mjs`).

```
npm run dev      # local dev server
npm run build    # validate data, astro check, build
npm run audit    # audit dist/ (run after build)
npm run verify   # build + audit
```

## Pages

- `/`, `/pest-control/` (general) and one page per pest, generated from `src/data/pests.json`
- `/how-it-works/`, `/about/`, `/contact/`, `/privacy/`

Each pest page covers what the problem looks like, treatment options, what affects the price, how to prepare
and what happens on the day, and HDB, condo, landed and office premises. `validate-data.mjs` fails the
build if any of those is missing.

## Rules (enforced by `scripts/validate-data.mjs`, `scripts/audit-build.mjs` and `scripts/copy-rules.mjs`)

- **Who runs it** (independence, user, 6 Oct 2026). The OurKampung team; no company is named (no company name, UEN,
  address or founding year). Structured data: the Organization is PestToClear, with `parentOrganization` OurKampung,
  and no `legalName`, `foundingDate` or `sameAs`.
- **Matching service.** Never "our technicians", "our team treats" or "our crew". The partner firm does the work.
- **No pest × town pages**, and nothing nested below a pest page. That pattern got OurKampung pruned.
- **No prices** until partners give real ranges: say the price comes after an inspection or quote.
- **No invented statistics, reviews, ratings or testimonials**, in copy or in JSON-LD.
- **NEA.** Say a firm is NEA-licensed only once that partner is checked, and with the official NEA source
  linked. Today the site states the law (vector control operators must be registered with NEA) and links
  NEA's page; it makes no claim about any firm. Any page that mentions NEA must link nea.gov.sg.
- **One GA4 event:** `generate_lead`, after FormSubmit confirms delivery, and it is the only key event (set 5 Oct).
  The site's code sends no `form_submit`, `button_click` or `form_start`. GA4's enhanced measurement (left on) does
  send `form_start` and `form_submit` by itself; those are never key events. Family standard (PORTFOLIO.md).
  GA4 property 557095049, moved to the OurKampung account (403279198) on 6 Oct; measurement ID G-G75E0X6YB1.
- **Form.** Subject is `PestToClear – <page>`. The PDPA line reads "Your details go to the OurKampung team, who pass
  them to the partner who'll quote for the job." The endpoint is FormSubmit's hashed alias (5 Oct 2026), so no
  email address appears in any page; the audit fails if one does. If a send fails, say so and keep what the visitor
  typed: no phone, WhatsApp or email fallback (family rule, 2 Oct).
- **Family links.** The footer's only family link is "Part of OurKampung" → `https://ourkampung.com/`, with
  `rel="nofollow"` (family revamp, 5 Oct 2026). About links `https://ourkampung.com/our-sites/`. No other header or
  footer links to sister sites. Never `rel="noreferrer"`.
- **Junk to Clear** is a separate disposal company the family refers jobs to, with no fees. One link only, on the
  bed-bug page where an infested mattress has to go: "Junk to Clear, a disposal company we refer jobs to". Never
  "our", "sister" or "same team" for it; plain link, no `sponsored`. The privacy policy says a disposal partner can
  be Junk to Clear.
